# dynamic-service-area — retired, now a redirect

This folder used to hold the single-page design reference for the Denver
city-detail template. The route has been re-architected as
`/service-areas/:locationId/(:serviceId)/`, generated by
`tools/generate-location-pages.pl` into real static pages under
`service-areas/`.

`index.html` here is now just a redirect stub to
[`/service-areas/denver-co/`](../service-areas/denver-co/index.html), kept so
old links/bookmarks to `/dynamic-service-area/` still land somewhere useful.
See the root [README.md](../README.md) for the current location/service
architecture.
